# auto-indie-wiki

a browser extension that automatically redirects you to indie wiki alternatives for popular websites.

## what is this?

a browser extension that automatically redirects you to indie wiki alternatives for popular websites.

this is a fork of [KevinPayravi/indie-wiki-buddy](https://github.com/KevinPayravi/indie-wiki-buddy) with a redesigned ui.

## original vs. this version

this is a fork of the [KevinPayravi/indie-wiki-buddy](https://github.com/KevinPayravi/indie-wiki-buddy) project.

### changes from original

- redesigned the ui with a dark pkm aesthetic. all text is now lowercase. extension renamed from indie-wiki-buddy to auto-indie-wiki. auto-update checking added.

## installation

download the `.xpi` file from releases and open it in firefox, or load it temporarily via `about:debugging` > this firefox > load temporary add-on.
